An open-source presenter

Welcome to
Lectern.

Present HTML slides with a real presenter view.

Speaker notes live right in the slide, in an aside with the class "notes". Only you see them.
How it works

You make the slides. Lectern presents them.

Write

Any HTML deck, by hand or with an AI agent. Or slide images.

Open

Add it to Lectern. Reorder slides and write notes.

Present

Slides on the projector. Notes, next slide and timer on your Mac.

Each card is a "step": it appears on the next click, on every screen at once.
Presenter view

Everything you need, nothing the audience sees.

Now & next

The current slide, and a picture of the next one.

Notes

Big, readable, and you set the size.

Timer

Starts when you start presenting.

Lectern finds the second screen by itself and puts the slides there.
Works with your clicker

Every key a USB clicker sends.

Page DownPage Up→←B · blank screenEsc · end
Clickers act like a small keyboard, so they work in any window.
1920

× 1080, scaled to fit every screen.

The projector, your presenter view and the thumbnails always match.

Decks are drawn at one fixed size and scaled, so nothing moves between screens.
Built for agents

An agent can build, check and fix your deck.

The MCP server lets an agent create decks, write notes, reorder slides, take screenshots and check every slide for problems.

See the mcp folder in the repo.
